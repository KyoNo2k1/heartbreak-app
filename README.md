# An Ủi 💗 — Trang web an ủi khi thất tình

Dự án Next.js (App Router) + Tailwind CSS + Framer Motion.

## Chạy thử

```bash
npm install
npm run dev
```

Mở http://localhost:3000

## Build production

```bash
npm run build
npm run start
```

## Gồm những gì

- Trang đầu: tim bay lên nền, câu an ủi ngẫu nhiên khi bấm nút.
- Bài tập thở: vòng tròn "thở" phồng lên xẹp xuống theo nhịp 4-4-6 giây.
- Danh sách vài bài hát gợi ý để nghe khi buồn.

## Tuỳ chỉnh

- Sửa câu an ủi trong mảng `quotes` ở `app/page.tsx`.
- Sửa màu sắc trong `tailwind.config.js` (màu `blush`).
- Đổi font ở `app/globals.css`.
